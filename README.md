# 🌐 AI Language Translator

## Overview

A Python-based desktop application that enables users to translate text into multiple languages through a simple and user-friendly graphical interface.

## 🚀 Features

- Translate text into multiple languages instantly
- Automatic language detection
- Clean and easy-to-use GUI
- Save translated text to a file
- Fast and lightweight application

## 🌍 Supported Languages

- English
- Hindi
- French
- Spanish
- German
- Arabic
- Japanese
- Russian

## 🛠️ Technologies Used

- Python
- Tkinter
- Deep Translator

## 📂 Project Structure

AI-Language-Translator/
├── translator_gui.py
├── requirements.txt
├── README.md

## ⚙️ Installation

### Install dependencies

pip install -r requirements.txt

### Run the application

python translator_gui.py
